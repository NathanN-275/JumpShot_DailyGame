# Glossary

- **Answer bank**: The set of canonical player names and aliases accepted for a trivia prompt.
- **Canonical answer**: The player name used to represent an accepted answer and its aliases.
- **Prompt**: An open-ended NBA trivia question that may have multiple valid answers.
- **Answer rarity**: An answer's scoring tier, which groups it as Common, Uncommon, Epic, or Super niche.
- **Scoring tier**: The point class assigned to an accepted answer: Dunk (10), Jumpshot (50), Three Pointer (100), or Half-Court Shot (200).
- **Run**: One game session of seven prompts, with 30 seconds to answer each prompt.
- **Scoring team**: The blue team controlled by the player; the red team is its opponent.
